# Belajar Command Line / Terminal

## Apa itu Command Line?

Command Line (CLI) adalah cara buat ngasih perintah ke komputer lewat tulisan, bukan klik-klik mouse kayak biasanya.

Awalnya emang keliatan ribet karena semuanya harus diketik. Tapi ternyata buat programmer ini malah lebih cepet daripada buka folder satu-satu.

Nanti pas belajar Git, Node.js, npm, React, Laravel, dll hampir semuanya bakal dijalanin lewat Terminal.

Jadi wajib banget ngerti dasar-dasarnya.

---

## Cara buka Terminal

### Windows

Bisa pake:
- CMD
- PowerShell
- Windows Terminal (lebih enak dipake)

Cara buka:
- Tekan tombol Windows
- Ketik "Windows Terminal"
- Enter

---

## Anatomi Terminal

Biasanya tampilannya kayak gini

C:\Users\DELL>

atau

username@pc:~$

Nah itu artinya kita lagi ada di suatu folder dan Terminal lagi nunggu command dari kita.

Kalau ada tanda

>

atau

$

berarti tinggal ketik command terus Enter.

# Dasar awal

Buat cek nama komputer

```cmd
hostname
```

Output

```cmd
el-bedull
```

Masuk ke folder Documents

```cmd
cd Documents
```

Kalau berhasil biasanya berubah jadi

```cmd
C:\Users\DELL\Documents>
```

Artinya sekarang posisi kita udah ada di folder Documents.

---

# Tiga command yang paling sering dipake

## pwd

Buat tau sekarang lagi ada di folder mana.

Kalau di Linux atau macOS

```bash
pwd
```

Kalau di Windows biasanya alamat foldernya udah keliatan di prompt.

---

## ls

Buat liat isi folder.

```bash
ls
```

Outputnya bisa berupa file atau folder yang ada di dalam directory sekarang.

Kalau di CMD Windows biasanya pake

```cmd
dir
```

---

## cd

Buat pindah folder.

Masuk ke folder project

```cmd
cd project
```

Balik satu folder

```cmd
cd ..
```

Balik ke folder Home

```cmd
cd
```

---

# Bikin folder

Pake command

```cmd
mkdir belajar-cli
```

Langsung kebikin folder baru.

Kalau mau banyak sekaligus juga bisa.

```cmd
mkdir html css js
```

---

# Bikin file

Kalau Linux/macOS

```bash
touch index.html
```

Kalau PowerShell

```powershell
New-Item index.html
```

---

# Copy file

```bash
cp index.html backup.html
```

Artinya isi index.html disalin ke file baru backup.html.

Kalau copy folder jangan lupa pake -r.

```bash
cp -r project backup-project
```

---

# Rename file

Ternyata command buat rename sama pindahin file itu sama-sama pake mv.

```bash
mv lama.txt baru.txt
```

---

# Hapus file

```bash
rm index.html
```

Hapus folder

```bash
rm -r project
```

Kalau ada command

```bash
rm -rf
```

Hati-hati banget.

Dia langsung ngapus semuanya tanpa nanya lagi.

# Command lain

clear
→ bersihin Terminal

cat
→ nampilin isi file

history
→ liat command yang pernah dipake

whoami
→ liat username yang lagi login

which
→ cari lokasi suatu program

man
→ buka dokumentasi command

---

# Tips

- Tab = auto complete nama file/folder.
- Panah atas = buka command sebelumnya.
- Ctrl + C = stop proses yang lagi jalan.
- Jangan asal copy paste command dari internet.
- Biasain baca dulu sebelum Enter apalagi kalau ada rm.

# Kesimpulan

Setelah nyoba sendiri ternyata Terminal gak seseram yang dibayangin. Yang penting hafal command dasar dulu kayak cd, ls, pwd, mkdir, sama rm. Sisanya nanti bakal kebiasa sendiri karena sering dipake pas ngoding.
