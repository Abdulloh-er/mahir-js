# BELAJAR DASAR COMMAND LINE / TERMINAL

## Apa itu Command Line?

Command Line atau yang sering disebut Terminal adalah sebuah program yang digunakan untuk menjalankan perintah ke komputer menggunakan teks. Jadi kita tidak perlu klik-klik folder atau file seperti biasanya, tetapi cukup mengetik command yang sudah disediakan oleh sistem operasi.

Awalnya memang terasa agak aneh karena biasanya kita terbiasa menggunakan mouse. Tapi ternyata hampir semua programmer menggunakan Terminal karena lebih cepat dan lebih efisien, apalagi kalau project yang dikerjakan sudah mulai besar.

Selain itu, banyak tools pemrograman yang dijalankan lewat Terminal, misalnya Git, Node.js, npm, React, Laravel, Docker, dan lain-lain. Jadi bisa dibilang Terminal adalah salah satu kemampuan dasar yang harus dipelajari sebelum masuk ke materi yang lebih lanjut.

Yang penting dipahami adalah Terminal bukan bahasa pemrograman, melainkan media untuk memberikan perintah kepada sistem operasi.

---

## Membuka Terminal di Sistem Operasi

Setiap sistem operasi punya aplikasi Terminal sendiri.

Kalau di Windows biasanya ada Command Prompt (CMD), PowerShell, dan Windows Terminal. Sekarang kebanyakan orang lebih memilih Windows Terminal karena tampilannya lebih modern dan bisa dipakai untuk banyak shell sekaligus.

Cara membukanya cukup tekan tombol Windows lalu cari "Windows Terminal" atau "PowerShell".

Kalau di macOS tinggal buka aplikasi Terminal melalui Spotlight (Command + Space), lalu ketik Terminal.

Kalau di Linux lebih gampang lagi karena hampir semua distro sudah menyediakan Terminal bawaan. Biasanya shortcutnya Ctrl + Alt + T.

Walaupun tampilannya sedikit berbeda, command dasar yang dipakai hampir sama.

---

## Anatomi Jendela Terminal

Saat pertama kali membuka Terminal biasanya akan muncul tulisan seperti ini.

username@computer:~/Documents $

Kalau dilihat sekilas memang kelihatan membingungkan, padahal setiap bagiannya punya arti.

* username menunjukkan nama pengguna komputer.
* computer menunjukkan nama perangkat yang sedang digunakan.
* ~/Documents menunjukkan posisi folder saat ini.
* tanda $ berarti Terminal sudah siap menerima command.

Semua command nantinya diketik setelah tanda tersebut lalu ditekan Enter.

Misalnya mengetik:

pwd

maka Terminal akan menampilkan lokasi folder yang sedang kita buka sekarang.

---

## Navigasi Folder di Terminal

Navigasi artinya berpindah dari satu folder ke folder lainnya.

Command yang paling sering dipakai adalah **pwd**, **ls**, dan **cd**.

### pwd

Command ini singkatan dari **Print Working Directory**.

Fungsinya untuk mengetahui kita sedang berada di folder mana.

Misalnya kita lupa sekarang ada di folder apa, tinggal ketik:

pwd

lalu Terminal akan menampilkan alamat folder tersebut.

---

### ls

Command ini digunakan untuk melihat isi folder.

Misalnya kita sedang berada di folder Documents lalu ingin melihat ada file apa saja di dalamnya.

Cukup ketik:

ls

Kalau ingin melihat file tersembunyi bisa menggunakan:

ls -a

Sedangkan kalau ingin melihat informasi file lebih lengkap seperti ukuran, permission, dan tanggal dibuat bisa menggunakan:

ls -l

---

### cd

Command **cd** berarti Change Directory.

Fungsinya untuk berpindah folder.

Misalnya ada folder bernama project.

Tinggal ketik:

cd project

Kalau ingin kembali ke folder sebelumnya:

cd ..

Kalau ingin langsung kembali ke folder Home:

cd

atau

cd ~

Kalau folder yang dituju berada di dalam folder lain juga bisa langsung ditulis path-nya.

Misalnya:

cd Documents/Belajar/Web

Semakin sering latihan menggunakan cd, semakin cepat kita terbiasa berpindah folder tanpa harus membuka File Explorer.

---

## Membuat Folder dan File

Kalau ingin membuat folder baru bisa menggunakan command:

mkdir

Misalnya:

mkdir latihan-terminal

Maka akan langsung dibuat folder dengan nama tersebut.

Kalau ingin membuat beberapa folder sekaligus juga bisa.

Misalnya:

mkdir html css javascript

Nanti ketiga folder tersebut langsung dibuat dalam satu command.

---

Untuk membuat file kosong biasanya menggunakan command:

touch

Contohnya:

touch index.html

Kalau ingin membuat beberapa file sekaligus juga bisa.

Misalnya:

touch index.html style.css script.js

Dalam satu kali Enter langsung jadi tiga file.

Kalau di Windows PowerShell biasanya menggunakan command New-Item.

---

## Copy, Paste, dan Mengganti Nama

Untuk menyalin file digunakan command cp.

Misalnya:

cp index.html backup.html

Artinya isi file index.html akan disalin ke file baru bernama backup.html.

Kalau yang disalin adalah folder maka perlu menambahkan opsi -r.

Contohnya:

cp -r project backup-project

Karena folder memiliki isi di dalamnya, maka proses copy harus dilakukan secara rekursif.

---

Kalau ingin memindahkan file menggunakan command:

mv

Misalnya:

mv index.html folderbaru/

Selain untuk memindahkan file, command mv juga bisa digunakan untuk mengganti nama file.

Contohnya:

mv tugas.txt tugas-lama.txt

Nama filenya berubah tetapi isi file tetap sama.

---

## Menghapus File dan Folder

Untuk menghapus file digunakan command:

rm

Misalnya:

rm index.html

Kalau file yang ingin dihapus lebih dari satu tinggal tulis semuanya.

Misalnya:

rm index.html style.css script.js

Kalau folder yang ingin dihapus masih kosong bisa menggunakan:

rmdir

Tetapi kalau folder tersebut masih memiliki isi, harus menggunakan:

rm -r

Contohnya:

rm -r project

Ada juga command yang cukup berbahaya yaitu:

rm -rf

Command ini langsung menghapus folder beserta seluruh isinya tanpa meminta konfirmasi terlebih dahulu.

Karena itu harus benar-benar hati-hati sebelum menekan Enter. Salah mengetik sedikit saja bisa menghapus file penting.

---

## Command Lain yang Berguna

Selain command utama, ada beberapa command lain yang sering dipakai.

### clear

Digunakan untuk membersihkan layar Terminal supaya tampilannya kembali kosong.

Kalau di Windows biasanya menggunakan:

cls

---

### cat

Digunakan untuk menampilkan isi file langsung di Terminal.

Misalnya:

cat README.md

Isi file tersebut akan langsung ditampilkan.

---

### more dan less

Kedua command ini digunakan untuk membaca file yang isinya panjang.

Bedanya, less lebih nyaman digunakan karena bisa scroll ke atas maupun ke bawah.

---

### whoami

Digunakan untuk mengetahui username yang sedang login.

Kadang command ini dipakai saat konfigurasi Git atau server.

---

### history

Digunakan untuk melihat daftar command yang pernah dijalankan sebelumnya.

Kalau lupa command apa yang tadi dipakai, tinggal ketik history.

---

### which

Digunakan untuk mengetahui lokasi suatu program.

Misalnya:

which node

Kalau Node.js sudah terinstall maka lokasi file executable-nya akan ditampilkan.

---

### man atau --help

Kalau lupa fungsi suatu command, kita bisa melihat dokumentasinya.

Contohnya:

man ls

atau

ls --help

Hampir semua command mempunyai halaman bantuan masing-masing.

---

## Tips dan Trik Menggunakan Terminal

Ada beberapa shortcut yang sangat membantu.

Yang pertama adalah tombol **Tab**.

Kalau mengetik nama folder tidak perlu sampai selesai. Tinggal ketik beberapa huruf pertama lalu tekan Tab.

Misalnya:

cd Doc

Tekan Tab.

Kalau hanya ada satu folder yang namanya Documents, Terminal akan otomatis melengkapinya.

Ini sangat membantu supaya tidak salah mengetik.

---

Shortcut berikutnya adalah tombol panah atas.

Dengan menekan ↑ kita bisa membuka kembali command yang pernah dijalankan sebelumnya.

Jadi tidak perlu mengetik ulang dari awal.

---

Kalau ada proses yang sedang berjalan dan ingin dihentikan bisa menggunakan:

Ctrl + C

Shortcut ini termasuk yang paling sering digunakan.

---

Biasakan membaca command sebelum menekan Enter.

Terutama command yang menggunakan rm karena file yang dihapus dari Terminal biasanya tidak masuk ke Recycle Bin.

---

Jangan hanya menghafal command.

Lebih baik memahami fungsi masing-masing command sehingga nanti saat menemukan command baru akan lebih mudah dipelajari.

---

## Terminal di VS Code

Visual Studio Code sudah menyediakan Terminal bawaan sehingga kita tidak perlu membuka aplikasi Terminal secara terpisah.

Cara membukanya bisa melalui menu:

Terminal → New Terminal

atau menggunakan shortcut:

Ctrl + `

Dengan adanya Terminal di VS Code, proses coding menjadi lebih praktis karena semua bisa dilakukan dalam satu aplikasi.

Misalnya menjalankan project, install package npm, menggunakan Git, menjalankan server, atau membuat folder baru.

Hampir semua programmer menggunakan fitur ini karena lebih efisien.
